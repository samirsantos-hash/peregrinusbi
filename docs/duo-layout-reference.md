# Duo layout reference

Reference: https://github.com/renocrypt/ios27-duo-kit (Apache-2.0).
Design sources consulted: README.md and docs/duo-ui.md.

The Peregrinus adaptation uses the reference's 48px action rhythm, capsule-based grouped navigation, separate content-local filters, inset sheets, and adaptive workspace. It retains Peregrinus DM Sans, existing HSL palette, routes, permissions, and financial data.

This is an independent CSS/DOM adaptation, not a copy of the kit's device, artwork, or shaders. Its experimental HTML-in-Canvas/WebGL compositor is not imported: it requires browser flags and cannot provide reliable cross-browser dashboard operation. Frost, hairline highlights, and reflections use progressive CSS enhancement with a solid fallback and reduced-motion support.

The repository's claims about Apple hardware/software are reference-project claims, not verified product specifications.
