# Glass interaction

- Panel motion uses scoped global tokens and marked surfaces; AuraReveal owns one-time outer-card entrances, excluding nested, fixed-overlay and already transformed surfaces to avoid duplicate motion or state remounts.

- IconeIndicador/TextoComIcones translate legacy symbol labels only at the presentation boundary; preserve diagnostic records and export values.

- GlassPointer updates local reflection coordinates only inside panel card surfaces; press feedback targets existing actionable markers, ignores nested controls, and respects reduced motion without mutating text or tilting navigation/Home.
